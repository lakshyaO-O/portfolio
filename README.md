# Portfolio

My personal portfolio website — a single-page site built with plain HTML, CSS and JavaScript. No frameworks, no build step.

**Live:** https://lakshyaO-O.github.io/portfolio/

## What's inside

| File | Purpose |
|---|---|
| `index.html` | All sections: hero, about, education, skills, projects, interests, achievements, contact |
| `style.css` | Editorial design system — warm cream background, charcoal type, muted olive accents |
| `script.js` | Mobile navigation toggle + gentle scroll-reveal animations |
| `img/` | Project images and icons |
| `my_pic.jpg` | Hero image |
| `photo_2026-11-24_18-49-30.jpg` | Smart India Hackathon 2026 internal-round selection graphic |

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deploy

Hosted on GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root.**
